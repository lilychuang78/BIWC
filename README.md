# BIWC Website

Starter structure for a clean HTML/CSS rebuild of the Berlin International Women's Club website.

## Main structure
- `index.html` — Home
- `about/` — About and Leadership
- `membership/` — Membership
- `activities/` — Activities and Activity Groups
- `events/` — Events
- `community/` — Charities and Partners
- `contact/` — Contact
- `css/style.css` — Shared styling for the entire website
- `js/main.js` — Shared JavaScript
- `images/` — Image folders by purpose
- `assets/icons/` — Icons

The files currently contain a reusable header/footer and placeholder page content.
